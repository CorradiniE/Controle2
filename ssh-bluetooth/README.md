# Acesso SSH via Bluetooth

Objetivo: acessar a Raspberry Pi por SSH a partir do PC (Windows 11) **via Bluetooth**,
sem Wi-Fi e sem monitor, iniciar o controle do motor e deixá-lo rodando de forma autônoma.

## Parâmetros da rede (conferir e preencher)

|---|---|

| Porta SSH | _a conferir_ |
| Tipo de rede (PAN/NAP, BNEP...) | _a conferir_ |
